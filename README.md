# QuestEdu 学问

> 一道题，问到你自己会做。

移动端优先的 AI 数学伴学：**只提问、不代做**。用苏格拉底式追问把一道高数/线代题拆成几小步，
学生每答一步 AI 追问一句；做完用滑块自评，再用一道同型变式题反过来验证这次自评准不准。

三重防幻觉：**所有数学结果由 SymPy 算**，LLM 只负责组织话术。

---

## 它要解决什么

| 痛点 | 常见产品 | 本项目 |
|---|---|---|
| 学生只想快点拿答案 | 搜题软件直接给完整解答 | 要答案会被挡回来，只把问题拆得更小 |
| "看懂了" ≠ "会做了" | 无感知 | 自评 4/5 却答错过 → **虚假自信预警（红灯）**，再用变式题裁决 |
| LLM 数学幻觉 | 数字靠模型猜 | 关键结果走 SymPy，展示前先算一遍 |

## 一次会话的闭环

```
选题 / 拍照
   → LLM 拆成 3~6 个节点（标准答案只留服务端）
   → 逐步追问：答对推进 / 答错升级提示 / 连错三次才补答
   → 整题做完，弹一次自评滑块（0~5 分）
   → 自评 vs 作答记录交叉校验 → 红灯 / 绿灯
   → 同型变式题独立完成（SymPy 算答案，只判对错不讲解）
   → 学习报告：知识点掌握度 + 虚假自信记录 + 变式成绩
```

顺序不能颠倒：**先自评、后变式**，自评才不会被变式结果污染。

## 快速开始

### 一键启动（推荐）

**Windows：双击仓库根目录的 `START.cmd`。**
**macOS / Linux：`./start.sh`。**

一件事都不用敲。它会：

- 自己挑一个**装了依赖**的 Python（PATH 里第一个不一定靠得住——本机常有好几个 Python，
  IDE 自带的那个往往一个包都没有，所以启动器会挨个探测 `import fastapi, sympy, uvicorn`）
- 默认端口 **8062**，被占自动往后顺延，不会出现"双击了没反应"
- 起服务 = 前后端同时就绪（页面由同一个进程挂出来），浏览器自动打开；
  打开后控制台窗口自动**最小化**到任务栏（不做真隐藏：停服务要 `Ctrl+C`，启动报错也要有地方看）
- 终端打印局域网地址和二维码，手机同一 WiFi 扫码即可
- 出错时窗口不关，停在原地让你看清原因

### 手动启动

```bash
pip install -r requirements.txt
python scripts/run.py            # 自动开浏览器；--no-open 关掉
python scripts/run.py --reload   # 改代码自动重启
```

也可以直接 `python -m uvicorn app.main:app --host 0.0.0.0 --port 8062`。

浏览器打开 <http://127.0.0.1:8062>。手机连同一 WiFi 时打开终端打印的局域网地址即可
（连不上多半是 Windows 防火墙拦了入站，放行一次 uvicorn 即可）。

**没有任何 API Key 也能完整跑通** —— 默认 `mock` 模式走内置题库，断网可用，
答辩现场网络出问题也不会开天窗。

## 手机怎么打开（三种入口）

齿轮 → **访问入口**。四条路是并行的，不是四选一——哪条通就用哪条：

| 入口 | 什么时候用 | 代价 |
|---|---|---|
| 局域网 | 手机和电脑同一个 WiFi（宿舍路由器、手机热点） | 校园网一旦开了客户端隔离就不可达；IP 还会被 DHCP 换掉 |
| **IPv6 直连** | 电脑有公网 IPv6（教育网/移动普遍有），手机在 4G/5G 下 | 地址由校园网分配，租期到了或重启会变；边界可能拦入站 |
| 公网隧道 | 校园网隔离、或者人不在电脑旁边 | 需要 `cloudflared`；链接公开，靠访问码挡人；每次开启域名都变 |
| WorkBuddy 托管 | 想让手机随时能看，甚至电脑关着 | 云端跑的是**独立副本**：空数据库、没有你的本地模型 |

**IPv6 直连**是最省事的一条：不装东西、不注册、不经过第三方，直接访问
`http://[2409:...]:8062`（IPv6 地址必须带方括号）。服务端为此同时监听
IPv4 和 IPv6——Windows 的 IPv6 socket 默认 `IPV6_V6ONLY=1`，直接绑 `::`
会**只**接 IPv6 把 IPv4 弄断，所以启动器手动把 `V6ONLY` 设为 0 做真双栈；
设置失败自动回退成只监听 IPv4，不会因此起不来。

IPv6 的两个坑：运营商普遍封 80/443 入站，所以端口用 8062 这种高位（正好也是默认值）；
校园网边界防火墙是否放行入站只能试了才知道，不通就换隧道。

**访问码**：走隧道和托管时，第一次打开要输 4 位数字（局域网直连不拦）。
访问码在"访问入口"页最下面能看到、也能一键换。它在 `.access.json` 里，已加进 `.gitignore`。

判定"要不要输码"看两件事：请求带没带 `X-Forwarded-For` / `CF-Ray` 这类反转头，
以及 `Host` 是不是本机地址。只看 Host 会被
`curl -H "Host: 127.0.0.1" https://xxx.trycloudflare.com` 绕过——实测过，所以两条都查。

### 装 cloudflared（隧道用）

```text
下载 https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
放到 E:\AI\cloudflared\cloudflared.exe
```

放好重启服务，设置页里那个开关就不再是灰的。程序按这个顺序找它：
`CLOUDFLARED` 环境变量 → `E:\AI\cloudflared\` → `PATH` → `Program Files`。

隧道用的是 **quick tunnel**（`cloudflared tunnel --url`），不用登录 Cloudflare 账号，
代价是域名随机、重启就换。要固定域名得有自己的域名 + `cloudflared tunnel create`。

### 发布到 WorkBuddy 托管

服务端已经支持沙盒要求的两件事：读 `PORT` 环境变量、绑 `0.0.0.0`。
发布前注意：`.env` 里有 Key，不要跟着上传；发布后云端是新的空数据库。
发布/下线得在 WorkBuddy 对话里做，页面上的"托管"只是记个链接方便打开。

## 接自己的模型

页面右上角齿轮 → 选运行方案（离线 / 云端 / 本地 / 混合）→ 填地址 / Key / 模型名 → 保存并测试。
配置写进 `.env`（已在 `.gitignore`），保存即生效、不用重启。

"离线"是一等选项，不是"清除配置"：随时切回来就用内置题库跑完整流程，
已填的云端与本地配置都还在，再切回去不用重填。
Key 那一格是密码框，每次打开都是空的——**留空即沿用已保存的 Key**，
要真删点下面的"清除已保存的 Key"。手打过的本地地址和模型名会记在浏览器里，
点"取消"也不会丢。

任意 OpenAI 兼容接口都能用：

| 场景 | INFERENCE_MODE | 行为 |
|---|---|---|
| 离线保底 | `mock` | 不联网，跑内置题库脚本（界面上可选，不用改文件） |
| 云端（DeepSeek/Kimi/OpenAI） | `cloud` | 只走云端 |
| 本地 LM Studio / llama-server / Ollama | `local` | 只走本地，不需要真 Key，默认 `http://127.0.0.1:1234/v1` + `qwen3.8` |
| 云端优先、本地兜底 | `hybrid` | 云端失败自动回落本地，两条错误都带出来 |

### 设备权限（一对多演示）

服务是一对多的：一台电脑跑服务，N 台手机扫码进来。默认**所有新连接的设备只能用离线题库（MOCK）**，
要让它用真模型，就在控制台趁它在线时授权一次：

- 权限按设备 IP 记（server / mock）。**掉线重连（90 秒无心跳后重新出现）一律重置回 MOCK**，
  连持久授权也一并清掉——在线期间授权、持续心跳则保留
- 学生端通过心跳（25 秒一次）感知权限变化：被授权 / 收回后**自动刷新首页**，
  自定义题目、拍照入口随之出现或隐藏——最多 25 秒生效，不用重扫二维码
- MOCK 权限设备拿到的题库接口也是离线形态，就算服务端此刻正跑着本地模型

### 本地模型的两个坑（都已在代码里兜住）

**一、慢是常态，不是卡死。** 实测本机 7B 级思考模型只有 2~5 字/秒，拆一道题
要几十秒到几分钟。所以：

- 本地路由的等待上限单独设成 900 秒（云端 120 秒），`connect` 只给 8 秒——
  地址填错要立刻报错，不能陪着读超时干等十几分钟
- **超时不重试**：模型还在算，重发只会让它排更久的队（LM Studio 日志里的
  `Client disconnected` 就是这么来的）；JSON 解析失败在本地也只重试一次
- 前端等待层会数秒，超过 15 秒直接说明"本地模型在推理，2~5 字/秒是常态"，还能取消——
  取消会通知服务端：排队中的请求直接出队、每次端点尝试前检查令牌；
  已在传输的推理会跑完，但结果**丢弃不入库**，也不再阻塞后面的学生

**二、思考型模型的 `content` 可能是空串。** Qwen3 / Gemma 这类模型把过程写在
`reasoning_content`、正文留空；JSON 里写 LaTeX 时又不会转义反斜杠（`\lim` 写成
`\l`），`\f` 还会被当成合法转义吞成换页符。这三件事都在 `llm.py` 里处理了。

### 拍照需要多模态模型

本地文本模型（`qwen3.8` 之类）不能看图。留空"本地看图模型"时，拍照按钮是灰的，
点击会直接告诉你缺什么，**不会**先把图片发给模型再等两分钟换来一个 400。
云端不填则拿主模型试一次，失败会翻译成人话（"当前模型不支持看图"）。

也可以直接复制 `.env.example` 为 `.env` 手动填。

## 界面里的几个约定

- **题目按学科分组**（微积分 / 线性代数），父级默认展开，点一下折叠
- 答题界面左上角有返回箭头，可退回题目列表重选题；没做完会先问一句
  "继续做题 / 离开"，手机的返回手势同样会被拦住
- 原题常驻条靠**手势**收放：按住它底部那条小横条往上拖就收起、往下拖就展开（跟手，拖到一半松手会回弹）；
  点标题行或点一下横条也能切换。出变式题时自动收起。**滚动对话不参与**——之前挂在 scroll 上会来回抖
- 键盘弹出时整个对话区跟着抬起来（按 `visualViewport` 的真实高度算），
  输入框不会被盖住
- 设置面板从**顶部展开**：内容多了可以滚；面板最底部那条小横条按住**往上滑**即可收起
- 头部有"当前生效 · xx"徽标，一眼看到现在跑的是哪个方案
- 入口二维码卡的右侧是切换钮（局域网/IPv6/隧道）和访问码；隧道没开时点"隧道"会滚到下面的隧道卡并高亮
- 设置**从顶部展开**；一级菜单（模型 / 访问入口）是下划线页签，二级（离线/云端/本地/混合）是胶囊按钮，两种外观刻意不同
- 说明性文字默认隐藏，面板右上角开「显示备注」才出现（选择记在浏览器里）
- 头部有独立的**扫码按钮**（齿轮旁）：一键跳到设置里的入口二维码卡并高亮
- 「入口二维码」卡：码放大放右侧，左侧是切换钮（局域网 / IPv6 / 隧道）和访问码；隧道没开时点"隧道"会定位到下方隧道卡
- 面板关闭有淡出 + 滑出过渡，不再是"啪一下消失"
- 头部还有**刷新按钮**（⟳，扫码钮旁）：主动同步权限与题库；做题中刷新会先确认，防止误触丢进度
- 输入框上方有一条**输入辅助符号条**（x²、`^{}`、√()、π、−…，可横滑）：点一下插入到光标处，
  带括号的自动把光标落进去等着填——语音转文字敲不了上标和根号，这条补上
- 首页「我的学习记录」：最近 30 次会话（进度 / 卡过几次 / 自评分），点开看完整报告；
  **30 分钟没有任何动静**的会话自动转「已超时」（不计入完答率的完成项）
- 有些答案在手机上很难敲（比如 $\frac{x^{2}}{2}$），这类节点带选项，点一下即可作答；
  选项的 `value` 和手输走同一条判定链路，不是特例分支
- 不展示"与作答记录基本吻合"这类系统自言自语，只有红灯（虚假自信）和绿灯（低估自己）才打断学生

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/info` | 应用信息 + 题库列表 + 模式 |
| GET | `/api/problems` | 题库摘要 |
| POST | `/api/sessions` | 创建会话，返回第一个问题（带 `req_id` 可随时取消） |
| POST | `/api/sessions/cancel` | 取消进行中的拆题（"先不做了"不再占用模型队列） |
| POST | `/api/sessions/{id}/messages` | 提交答案，返回下一问 |
| POST | `/api/sessions/{id}/self-assessment` | 提交自评分，返回校准结果 |
| POST | `/api/sessions/{id}/variant` | 出同型变式题（SymPy 预验证） |
| POST | `/api/sessions/{id}/variant/answer` | 变式作答，只判对错 |
| POST | `/api/ocr` | 上传题目照片，返回 LaTeX |
| WS | `/ws/chat` | 流式追问（断流自动退回 POST） |
| POST | `/api/heartbeat` | 学生端心跳：控制台在线设备列表的数据源 + 权限下发 |
| GET | `/api/sessions/{id}/report` | 学习报告 |
| GET | `/api/reports/{id}/radar` | 雷达图聚合数据 |
| GET | `/api/reports/{id}/export.csv` | 导出本次会话（Excel 可直接打开） |
| GET | `/api/qr` | 局域网入口二维码（SVG） |
| GET | `/api/llm` · POST `/api/llm/config` · POST `/api/llm/test` | 模型配置与自检 |

交互文档：<http://127.0.0.1:8062/docs>

`/ws/chat` 依赖 `websockets`（`uvicorn[standard]` 自带）。没装也能用——前端连不上
就退回 `POST /messages`，只是回复变成整段出现而不是逐字流；控制台会刷
`Unsupported upgrade request. / No supported WebSocket library detected`。
补装之后**要重启服务**：uvicorn 只在启动时探测一次，而且启动早于装包的老进程
会一直是坏的那个。

## 测试

```bash
python scripts/test.py          # 全部（不装 pytest 也能跑）
python scripts/test.py judge    # 只跑判定层
pytest                          # 装了 pytest 也可以
```

覆盖什么：数字抽取的宽容度（`2`/`二阶`/`x²`/`２` 都要判对）、语音口语翻译
（"五倍x的四次方"/"3x方"/"负十二" 能进判定链）、七道题完整闭环、
讨答案不推进、降维后再补答、每条回复以问句结尾、标准答案不外泄、
沙箱挡得住 `__class__` 遍历、重启后会话能续答、流式分片拼回来一字不差、
拆题取消令牌在排队/尝试前生效、设备掉线重连权限重置回 MOCK。

## 说明

- 前端公式用 KaTeX **本地化**（`app/web/vendor/`），不走 CDN —— 离线可用，也避免 CDN 被墙导致公式不渲染
- `.env` 明文存 Key，只在服务端使用，永不随接口下发（`/api/llm` 只回前 6 位）
- 内置题库 7 道：微积分（等价无穷小·难 / 极限 / 切线 / 定积分）+ 线代
  （范德蒙德四阶行列式 / 矩阵乘法·迹 / 特征值），全部 SymPy 可判定、自带同型变式
- 语音转文字的口语表述（"五倍x的四次方""3x方""负十二"）判定前先过
  `mathcheck.voice_to_expr()` 保守翻译；变式题回答含中文且在线时，先让模型
  **只做翻译**（分段描述 → `sign(x)` 形式），对错仍由 SymPy 符号比对裁决——模型不经手判定
- 节点的「期望值」是模型给的自由文本，入库前统一过 `mathcheck.clean_numeric()`：
  只留一个能被 SymPy 求值的 ASCII 表达式（`\frac{1}{2}` → `1/2`、`3x^2-3` → `3*x**2 - 3`），
  洗不出来就置空、判定退回关键词匹配——**宁可少一层，不可误判**
